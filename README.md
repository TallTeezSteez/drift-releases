# Drift releases

Installers and updates for **Drift**, Wyatt's notes app.

- **Download:** the newest **Latest** release below (`Drift_..._x64-setup.exe`).
- **Test** releases are marked *Pre-release*. They're built every hour from any new change and are what the Test channel
  (Drift › Settings › About) installs.
- **Public** = the release marked *Latest*. It only changes when a Test build is shipped (Actions › Ship Drift).

Every installer is signed, and Drift checks that signature before it installs an update.

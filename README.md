# Drift downloads

Wyatt's notes app. Every installer is signed, and Drift checks that signature before it installs an update.

## Download

- **Windows:** [Drift-Setup.exe](https://github.com/TallTeezSteez/drift-releases/releases/latest/download/Drift-Setup.exe)

These links always get the newest version. Older versions: [all releases](https://github.com/TallTeezSteez/drift-releases/releases).

**First time:**
1. Run the installer.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. You only do this once.

Drift updates itself after that.

More about Drift, with screenshots: https://draftlineapps.com/drift

## How a new version goes out

**Actions > Release > Run workflow.** Leave the version blank for the next number; add a line of "What's new" if you like. It builds and publishes on GitHub's free machines, and installed copies update themselves.

This repo is public so the downloads work for everyone. The app's code is in a private repo and isn't here.
